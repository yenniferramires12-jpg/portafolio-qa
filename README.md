# Portafolio QA — Yennifer Santana Liriano
Portafolio de QA Junior / Tester manual. Contiene pruebas reales ejecutadas en aplicaciones demo de práctica: 10 pruebas de API REST, una auditoría de HTML y accesibilidad con 6 reportes de defectos, y 13 casos de prueba manuales diseñados para una tienda demo.
- Las aplicaciones demo están rotuladas como demo/práctica.
- Los casos de la tienda demo están marcados como diseñados, no ejecutados.
